# Contributing

Read [AGENTS.md](AGENTS.md) and [docs/AGENT_WORKFLOW.md](docs/AGENT_WORKFLOW.md). People and agents use the same isolated-workspace, scoped-task, attributed-commit and PR workflow. Run `npm test` and `npm run check`; include relevant phone/desktop and encoded-media evidence for visible or media changes.

Keep authored Hebrew clinical copy, sourced order, and timing uncertainty intact. Discuss proposed cuts with the owner through a concrete review artifact; implementation tasks do not implicitly authorize changing the therapeutic program.

Report security issues through GitHub's private vulnerability reporting when enabled. Never put an exposed credential in an issue or PR. Public access does not grant a new content license; preserve existing rights notices.
