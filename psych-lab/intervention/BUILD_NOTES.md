# Full intervention

Purpose: experience the sourced psychology program end to end and measure its burden within a 30-minute app day. This implementation does not shorten or reorder the clinical program.

Current workbooks: Inner Voice is built from the owner's current `sources/activity-sheets/inner voice workout.xlsx` (2026-11-02; the September snapshot in `sources/inner-voice.json` stays as it was). Its answer buttons use the sheet's own Hebrew type names (לאמץ / לשחרר), and an answered card shows its type. Daily app minutes are summed from each day's activities in `sources/activity-sheets/Protocol.xlsx`; that sheet's own light-speech total for day 7 says 23, while its listed activities add up to 25; the owner confirmed 25 is correct (2026-11-02). `tests/test_inner_voice.py` checks both against the spreadsheets.

Where it is viewed: the sourced program is shown on the Psych Lab canvases (canvas/canvases.json), generated by canvas/build.mjs: Activities (one board per activity, each gap marked 'No source text'), Films & scripts, and Phone preview, which walks every session as core.mjs sequences it. The local preview website (app.mjs, activities.html, serve.py) was retired on 2026-11-02 at the owner's request.

Wording rule: the canvases show Hebrew only where a program source has it (titles, leads, thoughts, cards, reflection prompts and buttons). Interface words are English Lab labels in a system font, and screens whose program text is not in any source (motivation, post-practice question, in-practice breathing prompts, choice heading, Inner Voice feedback gaps, closing message) show a 'No source text' marker. tests/test_canvas.py checks every board with scripts/verbatim.py.

Design: retain the Lab's sage teal (#2B6A62), pale mint (#F5FBF8, #B3EFE4), amber (#FFDEA3), and ink (#171D1B). Hebrew patient screens use the existing Rubik/system font stack, large text, one task per screen, and large touch controls.

The current V0 timeline controls the 87 psychology sessions. These are psychology session IDs, distinct from app day 1 orientation. Current pre-pages, activity copy, context tables, and trailer mappings supplement it. Choice groups select one practice; selected methods get their own introduction when new. Repeat/library visits can omit previously seen introductions. No chosen practice is replaced with its trailer.

Timing distinguishes source media duration, planned practice duration, actual screen time, and accelerated/skipped review runs. Weekly non-psychology allocations are taken from Protocol.xlsx and remain an editable comparison assumption. Missing assets remain visible gaps; silence is never reported as a sourced recording. The Phone preview canvas times runs in a panel beside the phone: visible time per session and per step (paused while the page is hidden or the clock is paused), the content plan, the planned 30-minute day under Protocol.xlsx's light or heavy plan, and a log of runs kept in that browser. A run is a complete experience only when no media was left early or scrubbed, no practice ended early and no content was missing.

The original boards and 51 rendered videos remain available on the Original design canvas. Review notes are canvas comments. Nothing here writes to SharePoint or the production app.
