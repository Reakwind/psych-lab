Session 7 · מחשבות הן לא עובדות

Core idea. The same situation can be read in very different ways, and each reading changes how we feel and act. Thoughts are the brain's fast interpretations, sometimes caught in traps. Noticing them, and adding a question mark, opens a little room to respond differently.

Sound-off test. A call goes unanswered → three thoughts, three different days → a thought hardens into a "fact" → the brain fills gaps with shortcuts and traps → label it, step back → add a question mark → the door opens a crack.

Anchors
The unanswered call. One everyday situation the whole session returns to.
Inside the head. Session 2's cutaway: a puzzle the brain completes quickly, sometimes wrongly.
The question mark. Same words, one mark: a thought becomes something to check.
