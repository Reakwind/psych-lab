מפגש 56: ערכים ופעולה משמעותית

Core idea. Values describe how we want to live, while goals are particular things we want to do. A meaningful direction can remain when the goal or the size of the step changes.

Sound-off test. Daily tasks give way to a question about what matters. A flag is a goal; a compass is a direction. A family meal, a message, exercise or rest can express a direction differently. Two priorities can coexist without one prescribed answer.
