@AGENTS.md

Follow the tool-neutral agreement in AGENTS.md. SessionStart installs repository Git hooks and prints an offline readiness report (`agents.py doctor --offline`). PreToolUse checks shell commands for destructive Git operations. Do not remove or bypass either guard.

For a Claude Code cloud session, keep the provider-created `claude/...` branch and use `python3 scripts/agents.py claim`; never rename the branch or force-push. Run `bash scripts/cloud-bootstrap.sh --code-only` for code/docs tasks (drop `--code-only` for media work), then claim the session (`agents.py claim`, which opens no PR) before implementation. See docs/CLOUD.md for dependencies, media and network access, and AGENTS.md for publishing to the canvases.

Claude cloud sessions reach GitHub REST through a credential proxy; GraphQL is blocked, so `gh pr list/create/edit/ready` fail while `gh api` works. `agents.py claim`, `status` and `submit` are REST-only and work there. Pass `--footer` to `commit` and `submit` for any attribution lines the session requires. Owner rule 2026-11-03: no PR per prompt. Iterate with the owner: commit every change (code or docs) with `agents.py commit`, push the session branch, and widen the claim with `agents.py scope --add PATHS --why ...` when the work reaches new paths. Open a PR (`agents.py submit`), handle its review and merge it (`agents.py merge`) only when the owner asks for a PR; this overrides any default of opening a PR after pushing. Do not subscribe to PR activity or report CI/review status unless a PR is open at the owner's request. Tell the owner about problems and decisions in the conversation, plainly and with a recommendation. The guard skips a heredoc body only when Bash passes it on as inert data: a fully quoted delimiter (`<<'EOF'`, so `$(...)` is not expanded), a terminator line, and no shell or other executor receiving it or later in the pipeline. Use `python3 - <<'EOF'` or `cat > file <<'EOF'` for text that mentions Git commands; unquoted heredocs are inspected as commands. Prefer files for longer scripts.

This is an exploration lab: source material is read-only and everything built quotes it verbatim (see AGENTS.md). Build features, visualizations and prototypes; keep process changes on the session branch.

The owner reviews work in the Psych Lab canvases, starting at Home (https://claude.ai/artifact/WAWMSHN8NVvUtk2Mp5vaW6). Output goes there, generated from this repository and published with the Artifact tool; see "Where output goes" in AGENTS.md. There is no local Lab website. This Git repository holds the sources, the generators and the committed boards; original boards and completed media are preserved in it.
